- **`am`'s `output_noise_trajectory` draws from each column's own noise model.** Under
  edition 2 the draw was gated on the legacy `objfunc`, which edition 2 does not have, so every
  `traj_noise_*` file was all zeros, with no message. Each column is now drawn from the
  `neg_bin` noise model that scores it (its dispersion, its mean or median location, and its
  `cumulative` flag), and a column with any other noise model, including the default `chi_sq`,
  is refused when the configuration loads. Legacy `objfunc = neg_bin` / `neg_bin_dynamic` draws
  are unchanged.
