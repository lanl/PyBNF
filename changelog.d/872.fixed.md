- **On bngsim, a BNGL action with `sample_times` now writes BNG2.pl's rows (#872).** The bridge
  started the run at the first listed time, so with `sample_times=>[10,20,30]` it reported the
  initial state at t = 10 and shifted every row: a `de` fit of a decay recovered twice the true
  rate, with no warning. It also ran past a `t_end` below the last listed time. The run now
  starts at `t_start` and writes that row, then the listed times before the end, then `t_end`
  when the action gives one. The same holds for NFsim, for both `parameter_scan` paths, and for
  the clock a `continue=>1` action starts on. A grid with a negative `t_start`, or one that ends
  where it starts, is refused, as is `continue=>1` on NFsim, which BNG2.pl refuses. An edition-2
  time course with data before t = 0 is refused when the configuration loads. Edition-2 rows are
  otherwise unchanged.
