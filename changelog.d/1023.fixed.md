- **The minimum dependency versions PyBNF declares are now ones it runs on, and CI tests them
  (#1023).** `pyproject.toml` allowed pyparsing 2.4, but the configuration parser needs
  pyparsing 3, so an environment that kept pyparsing 2.x failed on the first `.conf`. Six other
  floors could not be installed from wheels on Python 3.12. The floors are now pyparsing 3.0,
  numpy 1.26, scipy 1.11.2, pydantic 2.0.2, libroadrunner 2.5.0, msgpack 1.0.6 and tornado 6.2.
  A new CI leg installs every runtime dependency at exactly its floor and runs the test suite.
