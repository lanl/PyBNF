- **An edition-2 BNGL model that `experiment:` lines simulate may carry only its network
  definition in its actions (#969, ADR-0152).** `generate_network`, `setOption`,
  `substanceUnits` and `version` are allowed, each as the only statement on its line; any
  other action, and `setModelName`, stops the job at load with an error naming the model file
  and the line. Move a `setParameter` into a `condition:` and delete leftover `simulate` or
  `write*` lines. PEtab export and import apply the same check, which replaces the export's
  list of actions it could drop, and the export now refuses a model bound the legacy way
  beside the experiments instead of leaving it out. Edition 1 is unchanged. A numbered action
  line (`1 generate_network(...)`) is now read as BioNetGen reads it (#963).
