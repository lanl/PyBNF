- **The bngsim bridges now read BNGL arithmetic as BioNetGen does (#1051).** They used Python's
  `eval`, where `^` is exclusive or, so `10^5` was 15 and `10^-12` was -2, with no error. This
  hit every parameter of the parameters block on the network-free bridge, quoted action
  arguments such as `"10^3"`, and initial amounts re-derived on the .net bridge. An action with
  an unquoted `^` or `**` is now refused on every backend, because BNG2.pl runs it as Perl,
  where `10^3` is 9. Quote the expression. Where PyBNF evaluates a minus sign directly before a
  power, such as `-2^2`, it now refuses it, because BioNetGen reads it two ways. Add parentheses.
