- **The bngsim bridges now read BNGL arithmetic as BioNetGen does (#1051).** They used Python's
  `eval`, where `^` is exclusive or, so `10^5` was 15 and `10^-12` was -2, with no error. This
  hit the parameters block on the network-free bridge, quoted action arguments such as
  `"10^3"`, and initial amounts on the .net bridge. A model is now refused, on every backend,
  if an action has an unquoted `^`, `**` or function call (BNG2.pl runs these as Perl, where
  `10^3` is 9), or a quoted `^` in a setting BNG2.pl does not evaluate, such as `atol`. Quote
  BNGL math only in `setParameter`, `setConcentration`, `addConcentration`, `t_start` and
  `t_end`. A negative number raised to a power, as in `-2^2`, is refused: add parentheses.
