- **The bngsim bridges now read BNGL arithmetic as BioNetGen does (#1051).** They used Python's
  `eval`, where `^` is exclusive or, so `10^5` was 15 and `10^-12` was -2, with no error. This
  hit the parameters block on the network-free bridge, quoted action arguments such as
  `"10^3"`, and initial amounts on the .net bridge. A model is now refused if an action has an
  unquoted `^`, `**` or function call (BNG2.pl runs these as Perl, where `10^3` is 9), a quoted
  `^` in a setting BNG2.pl does not evaluate, such as `atol`, or a negative number raised to a
  power, as in `-2^2`. On the .net bridge, a `setConcentration` naming a species bngsim cannot
  find, or a `stop_if` bngsim cannot read, was skipped silently. Such a model now runs on
  BNG2.pl under `bngl_backend = auto`.
