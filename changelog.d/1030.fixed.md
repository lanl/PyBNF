- **A data column that no simulation output matches now stops the fit with an error naming it
  (#817, #1030).** It used to be scored as one failed evaluation. A worker-scored fit such as
  `de` then dropped the column from every later job and finished as if it were absent, and a
  master-scored fit such as `lbfgs` scored every point `inf` and still reported a best fit. An
  `<observable>_SD` column beside a fitted observable is allowed when the noise model does not
  read it, so one data file can serve supplied, fixed and estimated noise fits, as lesson 36's
  does. Other errors that come from one parameter set are still scored as failed evaluations.
