- **With numpy 1.x on an AVX-512 CPU, the Liu–West filter (`job_type = lwf`) did not always write the same files twice, and an `lwf_continue` run did not always write what the uninterrupted run writes.** Converting a column of particles from sampling space computed `10.0 ** u` on a strided view. For such a view numpy 1.26 picks between Intel's SVML and the C library by memory address, and the two differ in the last bit for about a quarter of the values. Each column is now converted from a contiguous copy. The sampler histograms had the same defect in `log10` of a column of samples, and now take a contiguous copy too. numpy 2.x was not affected.
