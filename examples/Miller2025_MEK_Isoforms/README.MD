## Name
Miller2025_MEK_Isoforms

## Description
This file folder serves as supplemental material for the following publication:

Using PyBioNetFit to leverage qualitative and quantitative data in biological model parameterization and uncertainty quantification. Ely F. Miller, Abhishek Mallela, Jacob Neumann, Yen Ting Lin, William S. Hlavacek, and Richard G. Posner.

Published in _Frontiers in Immunology_: https://www.frontiersin.org/journals/immunology/articles/10.3389/fimmu.2026.1663008/full

## Files
Models (bngl), data (exp), and BPSL files (.prop) used in the global parameterization of the MEK isoform models in PyBioNetFit.

## Notes
These models were parameterized using PyBioNetFit v1.1.9
